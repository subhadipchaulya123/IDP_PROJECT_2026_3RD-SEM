## Output and Results

The project processes uncalibrated accelerometer and gyroscope measurements along with GPS data to perform IMU–GPS sensor fusion using GTSAM.

The pipeline synchronizes IMU measurements, converts GPS coordinates into a local East-North-Up (ENU) coordinate system, and estimates the fused trajectory.

### 1. IMU Synchronization Results

The accelerometer and gyroscope datasets are synchronized using their timestamps.

**Output File:** `output/Synchronized_IMU.csv`

This file contains synchronized accelerometer and gyroscope measurements with timestamps and three-axis sensor values.

### 2. GPS to Local ENU Conversion

GPS latitude and longitude coordinates are converted into a local East-North-Up (ENU) coordinate system.

This transformation represents geographic positions as local distances in meters relative to a reference origin.

**Reference Origin:**
- Latitude: 22.7409995°
- Longitude: 88.4605415°

| Parameter | Result |
|---|---:|
| GPS Readings Processed | 50 |
| East Coordinate | Meters |
| North Coordinate | Meters |
| Up Coordinate | Meters |

**Output File:** `output/GPS_ENU.csv`

The file contains GPS timestamps, latitude, longitude, and local east, north, and up coordinates.

### 3. IMU–GPS Sensor Fusion Using GTSAM

The synchronized IMU measurements and converted GPS positions are processed by the GTSAM-based fusion pipeline.

GTSAM uses the configured IMU and GPS constraints to estimate the device's trajectory.

The fusion process completed successfully and generated 50 optimized trajectory points.

**Output File:** `output/Fused_Trajectory.csv`

This file contains the estimated trajectory produced by the fusion pipeline.

### 4. Trajectory Statistics

The estimated trajectory was analyzed to determine the range of movement along the local east and north axes and the maximum distance from the origin.

| Parameter | Result |

These statistics describe the spatial extent of the estimated trajectory during the recording session.

**Note:** The east and north coordinate ranges represent the difference between the maximum and minimum coordinates along each axis. The maximum distance from the origin is calculated separately.
